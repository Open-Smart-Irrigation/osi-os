## Reading the inventory

Paths beginning `src/` or `demo/` are relative to `web/react-gui/`. `EDGE` means `conf/full_raspberrypi_bcm27xx_bcm2712/files/usr/share/node-red/`; `FLOW` means the sibling `flows.json`. Source symbols are the stable pointers when line numbers move. Named types mean their complete existing definition, including nullable fields; they are not permission to return a partial object. `api` means `src/services/api.ts`; `journalApi` means `src/services/journalApi.ts`; `F` means `src/types/farming.ts`; `J` means `src/types/journal.ts`; `H` means `src/history/types.ts`; `A` means `src/analysis/types.ts`.

Each row is a required contract/test ID. A row containing alternatives expands into one case per named alternative. `e`, `z`, `s`, `p`, `g` mean device EUI, numeric zone ID, schedule UUID, plot UUID and plot-group UUID. Path parameters are encoded by the existing client; EUIs are canonical uppercase in state. `void` below means the service client ignores the body: the simulated handler still performs the listed mutation and returns the owning source route's success envelope. It must never be implemented as an unconditional empty success.

For each write, the contract test calls the real service function through the installed simulator adapter, then calls the dependent real read. The browser case uses the named source surface to perform that write and checks the changed read in the UI after closing/reopening or navigating away/back. Validation cases assert status/body plus unchanged state. Unknown method/path combinations throw `501 unsupported`; normal inventory flows never reach that case.


## Persona, state and transport

Public reset starts as fictional researcher `Demo farmer`, with `ScopeProfile.features.scoped_access=false`, unrestricted `zone_uuids`/`plot_uuids` null, and a non-production session token. The role is the current presentation role; admin-only Users/Grants remain correctly unavailable. Registration creates a local researcher with the same fictional-farm access; login and logout preserve the farm model while the real `AuthSessionDataBoundary` replaces its session cache. Admin APIs are listed separately as permission-denied contracts, not exposed controls. Do not mint JWTs, retain real cloud credentials, or read native origin storage.

State owners: `farm` owns zones/assignments; `devices` owns device config/revisions/calibrations; `irrigation` owns commands/observed valve state/outcomes; `plans` owns valve schedules/push state; `triggers` owns zone schedules and evaluation history; `readings` owns timestamped synthetic measurements; `preferences` owns gateway settings; `sessions` owns local accounts/link status; `journal` owns plots/groups/entries/cycles; `analysis` owns saved views/history preferences/workspaces; `environment` derives summaries from farm/readings/config; `system` owns gateway status/fan/restart/support inbox. Runtime memory storage owns unchanged GUI preferences and client draft/workspace storage. Each reset replaces all these stores and revokes generated URLs.

Public gateway module defaults and values are all true: Data, Network, Gateway hub, Journal. Browser preferences start English/light, kPa, comfortable density, auto-refresh on, timezone `Africa/Kampala`, Quick journal capture; environment/water/scheduler/valve controls on, prediction advisory off. Settings can enable prediction. `SystemFeatureFlags` are `historyUxEnabled`, `historyComparisonEnabled`, `historyWorkspacesEnabled`, `historyAdvancedOverlaysEnabled` true and `historyCloudAiEnabled` false (no cloud AI control is being newly exposed). Preserve existing mobile user-agent gates in `DashboardHeader`; direct routes remain usable. Test all seven languages and both themes through actual native selectors.

The adapter accepts JSON request objects/serialized JSON, query params, AbortSignal, Axios responseType and auth-session metadata. Do not stringify array/object params by a generic `String(value)` loop: preserve the real client's parameter serialization and the endpoint's parser. A typed reply is `{status:number, headers:Record<string,string>, data:unknown}`; a typed failure preserves the same structure. Keep `Simulator.request()` as a data-returning compatibility method and introduce `requestResponse()` for the adapter. Model errors carry exact wire data; adapter rejects non-2xx with `AxiosError` containing it. `401` still passes through existing auth expiry rules; `/auth/login` and `/auth/register` use `skipAuthExpiry` and must not end a different current session on failed credentials. Aborted/superseded sessions cannot mutate a later session. No route delegates to native fetch/XHR/WebSocket/EventSource/beacon.

Source search at this base found no direct network calls outside Axios. `NetworkPage` uses FormData to read its HTML forms, then submits JSON; no multipart wire handler is required. Journal media tables exist on the edge, but this GUI exposes no upload/attachment action or media client. Keep the spec's “where offered” qualification; do not invent an uploader. Canvas PNG export is an existing action and is included below.
